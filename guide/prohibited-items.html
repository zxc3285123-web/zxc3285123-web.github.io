광고

기내 반입 금지 품목 목록은 항공사마다 수십 줄씩 됩니다. 다 읽어도 정작 내 가방 속 물건이 거기 없으면 소용이 없죠. 그래서 목록이 아니라 기준으로 접근하는 편이 훨씬 실용적입니다.

다섯 가지 원칙

  1. 날이 있거나 뾰족한 것 → 위탁
  2. 길고 단단해서 때릴 수 있는 것 → 위탁
  3. 흐르거나 짜서 쓰는 것 → 100ml 넘으면 위탁
  4. 불붙거나 터지거나 녹이는 것 → 기내·위탁 모두 금지
  5. 배터리가 분리되는 것 → 기내만 (위탁 금지)

이 다섯 줄로 대부분의 물건이 정리됩니다. 각각을 조금 더 보겠습니다.

1. 날이 있거나 뾰족한 것

과도, 커터칼, 캠핑 나이프, 양날 면도날, 조각도, 송곳, 못, 낚싯바늘, 다트핀, 화살. 전부 위탁입니다.

예외적으로 기내에 들어가는 것들도 있어요.

  • 가위 — 날 길이 6cm 이하면 가능
  • 손톱깎이 — 일반 크기는 가능. 긴 줄이 달린 제품은 거절될 수 있음
  • 일회용·카트리지 면도기, 전기면도기 — 날이 고정돼 있어 가능
  • 봉제용 바늘 — 대체로 가능하지만 보안요원 재량

맥가이버칼과 멀티툴은 칼날이 없는 모델이라도 거절되는 경우가 많습니다. 아끼는 물건이라면 무조건 부치는 짐에 넣으세요.

2. 길고 단단한 것

야구배트, 골프채, 당구 큐대, 등산 스틱, 죽도, 아령, 삼단봉. 날이 없어도 둔기로 분류돼 기내에 들어가지 않습니다.

애매한 것들도 여기 걸립니다. 셀카봉은 접으면 작은데도 펴면 봉이 되기 때문에 거절되는 일이 많고, 장우산도 끝이 뾰족해 위탁을 요구받는 경우가 흔해요. 3단 접이식 우산은 문제없습니다. 삼각대는 접었을 때 60cm 이하면 대체로 통과됩니다.

3. 액체·젤·스프레이

국제선은 100ml 이하 용기만, 1L 지퍼백 1개에 담아야 합니다. 자세한 내용은 액체류 100ml 규정에서 따로 정리했습니다.

4. 불붙거나 터지거나 녹이는 것

이 항목만은 기내도 위탁도 안 됩니다. 공항에서 버리는 수밖에 없어요.

  • 부탄가스, 캠핑가스 카트리지, 라이터 연료
  • 폭죽, 불꽃놀이 용품, 화약
  • 페인트, 시너, 스프레이 페인트, 강력 접착제
  • 표백제, 락스, 강산·강염기
  • 살충제, 농약
  • 호신용 스프레이, 최루가스, 전기충격기
  • 오일·연료식 손난로
  • 자동차 배터리, 차량용 점프스타터
  • 전동킥보드, 호버보드
예외

라이터와 안전성냥은 1인당 1개씩 몸에 지녀 기내로 가져갈 수 있습니다. 대신 위탁 수하물에는 넣을 수 없어요. 토치형·권총형 라이터는 기내도 불가입니다.

5. 분리되는 배터리

보조배터리, 여분 카메라 배터리, 드론 배터리, 전동공구 배터리, 전자담배. 전부 기내만 가능하고 위탁은 금지입니다. 자세한 기준은 보조배터리 규정에서 다뤘습니다.

보안이 아니라 검역에 걸리는 것

마지막으로, 규정은 통과했는데 도착 국가에서 막히는 경우가 있습니다. 벌금이 수십만 원 단위라 오히려 더 위험해요.

  • 신선 과일·채소 — 호주·뉴질랜드·미국은 대부분 반입 금지
  • 육류·소시지·육포·유제품 — 진공포장과 통조림도 예외가 아닌 나라가 많습니다
  • 씨앗·모종·화분 — 거의 모든 국가가 신고 대상
  • 흙이 묻은 등산화·캠핑 장비 — 호주·뉴질랜드는 특히 엄격합니다
  • 산호·상아·특정 동물 가죽 — CITES 협약으로 금지. 기념품 살 때 주의하세요

"버릴 각오가 안 되는 물건은 부치는 짐에"가 가장 안전한 원칙입니다. 개별 품목이 궁금하면 수하물 판별기에서 바로 확인해 보세요.
