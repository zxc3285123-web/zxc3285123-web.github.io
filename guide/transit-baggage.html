환승할 때 짐은 어떻게 되나 — 다시 찾아야 하나요?

대부분은 자동으로 따라오지만, 직접 찾아야 하는 경우가 분명히 있습니다.

여행 준비 최종 확인 2026-09-18

광고

환승이 있는 항공권을 처음 타면 가장 불안한 게 이겁니다. 내 짐은 어떻게 되는 거지? 결론부터 말하면 대부분 자동으로 옮겨지지만, 직접 찾아서 다시 부쳐야 하는 경우도 분명히 있습니다. 구분하는 방법이 있어요.

1. 체크인할 때 이것만 확인하세요

한 문장으로 끝납니다

첫 공항에서 짐을 부칠 때 직원에게 "최종 목적지까지 부쳐지나요?" 라고 물어보세요.

그리고 받은 수하물 태그의 도착지 공항 코드를 확인하세요. 최종 목적지 코드가 적혀 있으면 자동으로 따라옵니다.

예를 들어 인천 → 도쿄 → 로스앤젤레스 일정이라면 태그에 LAX가 찍혀 있어야 합니다. NRT(도쿄)라고 되어 있으면 도쿄에서 짐을 찾아야 한다는 뜻이에요.

2. 자동으로 옮겨지는 경우

  • 같은 항공사로 연결되는 일정
  • 제휴 항공사 — 스타얼라이언스, 스카이팀, 원월드 등 같은 동맹이거나 코드셰어 관계
  • 하나의 예약번호로 묶인 항공권

이 경우 환승 공항에서는 짐을 신경 쓰지 않고 다음 게이트로 이동하시면 됩니다.

3. 직접 찾아야 하는 경우

이럴 때는 짐을 찾아 다시 부쳐야 합니다
  • 따로 산 항공권 — 저비용항공사 두 개를 각각 예약한 경우가 대표적입니다
  • 제휴 관계가 없는 항공사 간 연결
  • 미국에 입국하는 경우 — 환승이어도 일단 입국 수속을 하고 짐을 찾아야 합니다
  • 일부 국가의 세관 검사 규정상 필요한 경우

미국 환승은 특히 주의하셔야 합니다. 미국은 최종 목적지가 아니어도 첫 도착 공항에서 입국 심사를 받고 짐을 찾은 뒤 다시 부쳐야 합니다. 그래서 환승 시간이 최소 3시간은 필요해요. 2시간짜리 일정을 잡으면 놓칠 가능성이 높습니다.

4. 최소 환승 시간(MCT)

공항마다 최소 환승 시간이 정해져 있습니다. 이 시간보다 짧으면 항공권 예약 자체가 안 되지만, 이건 어디까지나 최소치예요.

상황권장 여유
같은 터미널, 같은 항공사1시간 30분
터미널 이동 필요2시간 이상
짐을 찾아 다시 부쳐야 함3시간 이상
미국 환승3시간 이상

연결 시간이 짧을수록 짐이 못 따라올 확률도 올라갑니다. 사람은 뛰어서 갈아탔는데 짐은 못 옮겨진 경우가 흔해요. 이럴 때를 대비해 기내 가방에 하루치를 챙겨두시면 좋습니다.

5. 환승 중에 조심할 것

면세품 봉투를 뜯지 마세요

첫 공항 면세점에서 산 액체는 STEB 봉투가 밀봉된 상태여야 다음 구간 보안검색을 통과합니다. 뜯으면 압수돼요. 자세한 건 액체류 규정에 있습니다.

보안검색을 다시 받습니다

환승 공항에서도 보안검색을 다시 통과해야 하는 경우가 많습니다. 첫 공항에서 통과했다고 안심하고 물병을 들고 있으면 버려야 해요.

나라별 액체 규정이 다를 수 있습니다

대부분 100ml 국제 기준을 따르지만, 일부 공항은 더 엄격하게 봅니다. 환승 공항의 규정도 한 번 확인해 두면 좋아요.

6. 따로 산 항공권의 위험

저비용항공사를 조합해 싸게 가는 방법이 있죠. 가격은 매력적이지만 앞 비행기가 지연되면 뒤 비행기는 책임지지 않습니다. 하나의 예약으로 묶인 항공권이라면 항공사가 다음 편을 다시 잡아주지만, 따로 산 것은 그냥 날아가요.

따로 산 항공권으로 환승하실 거라면 최소 4시간, 가능하면 하루 여유를 두세요. 짐도 직접 찾아 다시 부쳐야 하니 시간이 더 필요합니다.
