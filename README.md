# 수하물 신호등

항공 수하물 250개 품목을 기내 · 위탁 · 반입금지로 판별해 주는 정적 웹사이트입니다.
빌드 도구 없이 그대로 GitHub Pages에 올릴 수 있습니다.

---

## 1. 사이트 정보

운영자 정보와 주소는 이미 채워져 있습니다. 바꾸실 일이 생기면 `_build.py` 맨 위 다섯 줄만 고치고
`python3 _build.py` 를 다시 실행하면 사이트 전체(개인정보처리방침, 문의, 사이트맵, canonical)에 한 번에 반영됩니다.

```python
SITE_NAME = "수하물 신호등"
SITE_URL  = "https://zxc3285123-web.github.io"   # 끝에 / 붙이지 마세요
OWNER     = "수하물 신호등 운영자"
EMAIL     = "zxc3285123@gmail.com"
EFFECTIVE = "2026년 9월 11일"
```

나중에 개인 도메인을 연결하면 `SITE_URL` 을 새 주소로 바꾸고 다시 빌드하세요.

## 2. GitHub Pages에 올리기

```bash
git init
git add .
git commit -m "수하물 신호등 최초 배포"
git branch -M main
git remote add origin https://github.com/<사용자명>/<저장소명>.git
git push -u origin main
```

저장소 → **Settings → Pages** → Source를 **Deploy from a branch**, 브랜치를 **main / (root)** 로 지정하면 1~2분 뒤 공개됩니다.

`.nojekyll` 파일이 들어 있어 Jekyll 처리를 건너뜁니다. 지우지 마세요.

### 커스텀 도메인 (애드센스에는 사실상 필수)

1. 도메인을 구입합니다 (가비아 · 후이즈 · Cloudflare 등, `.com` 기준 연 1~2만 원)
2. DNS에 아래 레코드를 추가합니다
   - `A` 레코드 → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - 또는 `www` 서브도메인이면 `CNAME` → `<사용자명>.github.io`
3. Settings → Pages → Custom domain에 도메인을 입력하고 **Enforce HTTPS** 체크
4. 저장소 루트에 `CNAME` 파일이 자동 생성됩니다

## 3. 애드센스 붙이기 (승인 후)

1. **게시자 코드** — 모든 HTML `<head>`에 주석 처리된 한 줄이 있습니다. 주석을 풀고 `ca-pub-0000000000000000`을 본인 게시자 ID로 교체
2. **ads.txt** — 루트의 `ads.txt`에서 `#`을 지우고 게시자 ID 교체
3. **광고 단위** — 본문의 `<div class="adslot">` 안에 애드센스에서 발급받은 광고 코드를 붙여 넣기

승인 심사 중에는 코드를 넣어 둔 상태여야 합니다. 광고가 나오지 않는 건 정상이에요.

## 5. 품목 추가·수정하는 법

품목은 **`_items.py` 한 파일**에만 들어 있습니다. 여기를 고치고 아래 한 줄을 실행하면
판별기 검색과 정적 목록이 함께 갱신됩니다.

```bash
python3 _build.py
```

### 한 줄 추가하기

`ITEMS = [` 아래 아무 곳에나 한 줄을 넣으면 됩니다. 분류가 같은 것끼리 모아 두면 보기 편해요.

```python
{"n": "충전식 무선 고데기", "e": "🔋", "c": "전자·배터리", "v": "cabin", "ox": "○✕",
 "k": "무선 고데기 충전식고데기 코드리스 무선아이롱",
 "d": "리튬배터리 내장이라 <em>위탁 금지</em>. 기내로 가져가세요."},
```

| 항목 | 뜻 |
|---|---|
| `n` | 화면에 보이는 품목 이름 |
| `e` | 아이콘으로 쓸 이모지 하나 |
| `c` | 분류. 파일 위쪽 `CATS`에 있는 것 중 하나 |
| `v` | 판정 — `both` 모두 가능 · `cabin` 기내만 · `checked` 위탁만 · `cond` 조건부 · `ban` 둘 다 금지 |
| `ox` | 두 글자. 앞이 기내, 뒤가 위탁. `○` 가능 · `△` 조건부 · `✕` 불가 |
| `k` | **검색에 걸리게 할 다른 이름들.** 띄어쓰기로 구분 |
| `d` | 설명. `<em>강조</em>` 태그를 쓸 수 있습니다 |

`v`와 `ox`는 보통 짝이 맞지만, 조건이 한쪽에만 걸리는 경우 따로 지정합니다.
예를 들어 가스식 고데기는 `"v": "cond", "ox": "△✕"` — 기내는 조건부, 위탁은 불가입니다.

### 선택 항목 두 가지

```python
"calc": "wh"   # 보조배터리 용량 계산기를 붙입니다 ("ml" 이면 액체 용기 계산기)
"dom": {"v": "both", "ox": "○○", "d": "국내선은 용량 제한이 없습니다."}
               # 국내선을 골랐을 때 이 값으로 덮어씁니다. 액체류에 주로 씁니다
```

### `k`(별칭)를 잘 채우는 것이 핵심입니다

297개 품목 모두 별칭이 평균 7개씩 붙어 있습니다. 새로 추가하는 품목에도 같은 수준으로 채워 주세요.
브랜드명(다이슨, 락앤락, 에프킬라), 영어(gopro, kf94), 줄임말(디카, 전담),
옛날 이름(호치키스, 바리캉)까지 넣어 두면 검색이 훨씬 잘 걸립니다.

검색은 **띄어쓰기를 무시**하므로 `무선 선풍기`와 `무선선풍기`가 같게 취급됩니다.
그래도 사람들이 부르는 이름은 제각각이라, 떠오르는 대로 넣어 두세요.
별칭으로 찾아지면 화면에 "‘무선 선풍기’ → 휴대용 선풍기로 찾았어요"라고 알려 줍니다.

초성 검색도 자동으로 됩니다. `ㅂㅈㅂㅌㄹ` 를 치면 보조배터리가 나와요. 따로 설정할 것은 없습니다.

### 새 분류를 만들고 싶다면

`_items.py` 위쪽 `CATS` 목록에 이름을 추가하고, 품목의 `c`에 같은 이름을 쓰면 됩니다.
필터 버튼과 정적 목록의 순서는 `CATS`에 적은 순서를 따릅니다.

## 6. 항공사 추가·수정하는 법

항공사는 **`_airlines.py`** 한 파일에 있습니다. 형식은 이렇습니다.

```python
{"id":"xx","name":"항공사 이름","code":"XX","tag":"동남아 항공사",
 "cabinKg":"7kg","cabinSize":"56×36×23cm","cabinCnt":"가방 1개 + 개인 소지품 1개",
 "checkedKg":"23kg","checkedSize":"1개 · 삼변 합 158cm 이내","checkedNote":"운임별 상이",
 "extra":"카드 아래에 한 줄로 붙는 메모",
 "link":"https://공식 수하물 안내 주소"},
```

- `id` 는 다른 항공사와 겹치지 않는 짧은 영문 키 (보통 편명 코드 소문자)
- `tag` 는 선택 상자의 그룹 제목. **같은 그룹끼리 붙여서** 적어야 묶여 나옵니다
- 숫자는 모두 **국제선 이코노미 기본 운임** 기준으로 통일했습니다
- `link` 는 반드시 공식 페이지로. 사용자가 직접 확인할 수 있어야 합니다

고친 뒤 `python3 _build.py` 를 실행하면 판별기 선택 상자와 홈의 비교표가 함께 갱신됩니다.

## 7. 가이드 문서 추가하는 법

1. `_posts1.py` ~ `_posts4.py` 중 아무 파일이나 열어 `POSTS["키"] = dict(...)` 형식으로 새 문서를 추가
2. `_build.py`의 `ORDER` 리스트에 그 키를 넣기 (목록에 보이는 순서입니다)
3. `python3 _build.py` 실행 → `guide/` 아래에 HTML이 생성되고 사이트맵·목록·홈이 함께 갱신됩니다

본문에는 `<h2>` `<h3>` `<p>` `<ul>` 과 `.callout` `.tablewrap` 같은 클래스를 그대로 쓸 수 있습니다.
기존 글을 열어 형식을 참고하세요.

## 8. 검색엔진이 보는 콘텐츠

`tool.html` 아래쪽에는 250개 품목이 **정적 HTML 표**로도 들어 있습니다 (`#all-items`).
검색창은 자바스크립트로 동작하지만, 자바스크립트를 실행하지 않는 크롤러에게도
품목명과 설명 약 12,500자가 그대로 읽힙니다. 애드센스 심사와 검색 노출 모두에 중요한 부분이니
`gen_static.py` 로 다시 만들기 전에는 이 구역을 지우지 마세요.

.nojekyll           Jekyll 비활성화

`_build.py`, `_items.py`, `_posts*.py`, `_tool/`, `__pycache__`는 완성된 사이트가 도는 데는 필요 없습니다.
다만 나중에 품목이나 문서를 고치려면 있어야 하니 저장소에 함께 올려 두시길 권합니다.
